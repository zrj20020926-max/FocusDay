# FocusDay

FocusDay 项目仓库。

## 成就与主题

成就基于实际任务和有效专注数据，早晨和夜间以设备本地时区下的专注完成时间为准。解锁后会保留记录。两台设备同时离线达成同一里程碑时，各自可能先显示提示，联网后会采用云端首条有效解锁记录。

在「设置 → 外观与布局」可切换暖纸白、森林绿、深夜模式和海盐蓝。选择「跟随系统」后，系统浅色使用暖纸白，系统深色使用深夜模式。

## 通知与提醒

在「设置 → 通知提醒」管理应用内提示、浏览器系统通知和提示音。系统通知需要在当前浏览器中主动授权。在任务详情里可设置指定日期和时间，或相对于截止日结束的提前提醒；习惯详情里的固定时间按设备本地时间执行，只在启用习惯的计划日提醒。

页面打开时会定期检查提醒，并在重新获得焦点时复核。后台节流、设备休眠和系统通知设置可能导致延迟或静音。任务与当天的习惯提醒最多补发最近一小时的事件；计时恢复时仅提示最近十分钟内的最新阶段。重复通知的收执保存在当前浏览器，各设备独立授权和投递。

关闭页面或浏览器后，这个前端无法继续检查时间。关闭页面仍需送达的提醒需要服务端调度、Web Push 订阅和 Service Worker，并取决于浏览器与操作系统是否允许接收后台推送。本项目当前提供页面运行期间的提醒。
