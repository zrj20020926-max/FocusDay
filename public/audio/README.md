# Focus Day environment audio

Focus Day 6.1 does not ship third-party audio files. Rain, forest, ocean and café textures are generated locally in the browser with the Web Audio API from procedural noise, filters and low-frequency modulation.

- Source: Focus Day project code (`AmbientAudioService.ts`)
- License: same license as this project
- Network requests: none
- Attribution required: none

The `/public/audio` directory is reserved for future self-produced or separately licensed loop files. Any file added later must document its author, source URL, license, editing history and attribution requirements here before it is used by the application.
